Application

Sable Mail

Sable Mail is a private, self-hosted service that connects to the developer's own Gmail account with read-only access. It reads service notification emails (alerts from uptime monitors, status pages, and similar automated senders) and turns them into status entries on private dashboards, including an Uptime Kuma instance.

What it does

  • Signs in with Google using OAuth, requesting read-only Gmail access.
  • Looks for notification emails from known monitoring and status senders.
  • Shows the state those emails describe (up, down, incident, resolved) on dashboards the developer runs for themselves.

What it does not do

  • It never sends, deletes, labels, or changes email.
  • It does not sell, share, or advertise with any data, and does not use Google user data to train AI models.
  • It is not a public service. Accounts belong to the developer.
